Nhập Điểm & Điều Phối Bất Đồng Bộ

Quy trình: gRPC Client (Xác thực sinh viên) → Postgres (Lưu điểm) → Kafka Event (Bắn topic student-grade-events)

Phiếu Nhập Điểm

Tiến trình điều phối Microservices:
1. gRPC Client → student-service (9091): Xác thực ID sinh viên.
2. Spring JPA: Lưu điểm môn học vào grade_db.
3. Kafka Producer: Gửi StudentGradeEvent sang topic 'student-grade-events'.
4. analytics-service: Tự động cập nhật GPA & trạng thái ĐỖ/TRƯỢT.
